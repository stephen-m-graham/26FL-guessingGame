# 4x4 Grid Guessing Game
## 26FL CIT-1154 at Lethbridge Polytechnic
### Purpose
This program is to illustrate some fixed size array wrapped in a class with accessors.
It is intended to be inspirational to building a game of Battleship
### Notes
This is not rigorously programmed or tested.
Input in the testing program outside the range of [0-3] will be out of range with no error handling or exceptions
Character input when numbers are expected are unhandled and may cause non-terminating loop
